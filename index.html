Project Overview

BinGo (Bin + Go)

Visual-first waste sorting guide for non-Koreans

BinGo is a visual-first web guide for international students, residents, and tourists in Korea who find waste sorting unfamiliar and struggle with Korean-only information. Instead of complex Korean text, it uses clear images and an intuitive, quiz-style card interface in English to show exactly where each item belongs: recyclables, general waste, or food waste.

Why This Topic Matters

Many non-Koreans don't know which bin a specific item belongs in, which leads to unexpected fines and improper recycling. Detailed rules vary by municipality, but the basic rules for classifying items are the same everywhere. By turning these shared rules into simple, English-friendly image cards, BinGo lowers the information barrier and helps everyone build correct recycling habits.
