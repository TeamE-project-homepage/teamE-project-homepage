## 데이터 해석

- `category_code`는 품목 분류이고 `disposal_type_code`는 배출 유형이다. 예를 들어 `FO`의 달걀 껍데기·생선뼈는 `FOOD`가 아닌 `GENERAL`이다.
- 가전은 기존 배출 유형 중 `RECYCLABLE`을 사용하되 별도 폐가전 수거 경로로 안내했다. `AP` 품목에 일반 재활용품의 배출 일정·수거함을 그대로 적용하면 안 된다. 의류 역시 폐의류 전용수거함의 수거 조건을 확인해야 한다.
- `FOOD` 품목의 `recyclable=CONDITIONAL`은 이물질·물기를 제거한 뒤 음식물 별도 수거를 통해 자원화할 수 있다는 뜻이다. 화면에는 음식물 배출 유형을 함께 표시해야 한다.
- 가구·기타 대형폐기물의 `NOT_RECYCLABLE`은 일반 재활용품 수거함 대상이 아니라는 의미다. 재사용·별도 자원회수가 불가능하다는 뜻은 아니다.
- `_verification=VERIFIED`는 기재한 공식 출처에서 품목 또는 분류 근거를 확인했다는 뜻이다. 서울 25개 자치구의 모든 조건을 검증했다는 의미는 아니다. 자료의 일반 규칙을 품목에 적용한 경우와 지역별 차이는 `_notes_ko`에 적었다.
- 수거 장소·요일·시간·수수료는 거주 자치구 또는 수거 운영자의 최신 안내에 따른다. 이번 품목 추가에서는 기존 자치구별 규칙 데이터를 수정하지 않았다.
- `image_url`은 실제 이미지 확보 전까지 비워 뒀다. `clip_prompt`는 품목을 묘사하는 입력 문구이며 모델 인식 성능을 검증한 결과가 아니다.
