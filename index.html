Project Overview

BinGo (Bin + Go)

Visual-first waste sorting guide for non-Koreans

BinGo is a visual-first web guide for international students, residents, and tourists in Korea who find waste sorting unfamiliar and struggle with Korean-only information. Instead of complex Korean text, it uses clear images and an intuitive, quiz-style card interface in English to show exactly where each item belongs: recyclables, general waste, or food waste.

Why This Topic Matters

Many non-Koreans don't know which bin a specific item belongs in, which leads to unexpected fines and improper recycling. Detailed rules vary by municipality, but the basic rules for classifying items are the same everywhere. By turning these shared rules into simple, English-friendly image cards, BinGo lowers the information barrier and helps everyone build correct recycling habits.

Goals & Features

Project Goals

  • Eliminate Language Barriers: Provide intuitive, visual-first recycling guidelines for non-Koreans.
    (외국인을 위한 직관적·시각적 중심의 분리수거 가이드를 제공하여 쓰레기 배출 과정의 언어 장벽을 해소합니다.)
  • Reduce Improper Disposal & Fines: Make waste disposal information quick and accessible within 3 seconds to lower improper waste disposal and fines.
    (3초 이내로 확인할 수 있는 신속한 정보 접근성을 통해 외국인 거주자의 오배출 및 관련 벌금 부과 사례를 줄입니다.)
  • Enhance User Engagement: Simplify complex recycling rules into clear visual choices through an interactive, card-based UI.
    (복잡한 분리수거 규칙을 명확한 시각적 선택지로 단순화한 인터랙티브 카드 기반 UI를 통해 사용자 참여도를 높입니다.)

Planned Features

  • Visual Item Lookup (Fast Search): Search items in English or browse by pictogram categories (e.g., Plastic, Paper, Trash) to get instant disposal results (Recycle vs. General Waste vs. Food Waste).
    (시각적 품목 검색: 영어 검색 또는 픽토그램 카테고리 탐색을 통해 배출 방법을 즉시 확인)
  • Step-by-Step Action Guides: Minimalist 3-step visual instruction for each category (e.g., Empty → Rinse → Detach label).
    (단계별 시각 행동 가이드: 카테고리별 3단계 핵심 수칙을 픽토그램으로 제시)

What Success Looks Like

Success will be measured by how quickly and easily a non-Korean user can determine the correct waste disposal method without needing translation tools (within 3 clicks). Visually, it features a clean, text-light web interface. Socially, it contributes to lower waste contamination rates and smoother community integration.
(외국인 사용자가 번역기 없이 3번의 클릭 이내에 올바른 분리배출 방법을 파악할 수 있도록 텍스트를 최소화한 인터페이스를 제공하며, 지역사회 적응 및 쓰레기 오염률 감소에 기여합니다.)
