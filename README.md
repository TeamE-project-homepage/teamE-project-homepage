# BinGo

BinGo is a web app that helps international students and foreign residents in Seoul find waste sorting and disposal instructions in English.

## Planned Features

- Search for waste items in English or browse by category.
- View visual item guides and step-by-step disposal instructions.
- Select a Seoul district to see local disposal rules.
- Upload a photo to help identify an item.

## Project Status

BinGo is currently in development.
