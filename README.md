# BinGo

> Waste sorting and disposal guidance in English for international students and foreign residents in Seoul.

Disposal instructions can vary by district. BinGo is designed to help users identify an item, find the relevant local rules, and see how to dispose of it step by step.

**Project status** · In development

## Planned Features

| Feature                              | What users can do                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------------------- |
| English search and category browsing | Search for a waste item in English or browse by category.                             |
| Visual item guides                   | Identify common items from visual cards and see how they are classified for disposal. |
| Step-by-step instructions            | See how to prepare an item and where to put it.                                       |
| District-specific guidance           | Select a Seoul district to view its local disposal rules.                             |
| Photo-based recognition              | Upload a photo to help identify an item.                                              |
